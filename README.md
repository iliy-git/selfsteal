# 🌐 SelfSteal SNI (Steal Yourself) — Автоматический установщик

Автоматическое развертывание персонального сайта-визитки в Docker и автоматическая настройка **VLESS REALITY** в панели **3x-ui** для маскировки трафика под собственный домен (**SelfSteal SNI**).

---

## 🎯 Зачем нужен SelfSteal?

Многие современные хостинг-провайдеры (Node / Nodehost, Hetzner и др.) запрещают использовать в REALITY чужие популярные домены (`microsoft.com`, `apple.com`, `samsung.com`, `nvidia.com`) и расценивают это как нарушение TOS или фишинг. 

**Решение — SelfSteal (маскировка под себя):**
1. Вы регистрируете собственный домен (или берете бесплатный) и направляете его A-запись на IP своего сервера.
2. Скрипт разворачивает в Docker стильный сайт-визитку на порту `127.0.0.1:8443` и выпускает официальный сертификат **Let's Encrypt**.
3. Скрипт автоматически настраивает Xray / 3x-ui на прослушивание порта **443**:
   * Обычные HTTPS-запросы, браузеры, боты и DPI-сканеры провайдера Xray прозрачно перенаправляет (Fallback Dest) на `127.0.0.1:8443` — они видят настоящий легитимный веб-сайт с идеальным зеленым SSL.
   * Ваши VPN-клиенты с валидным ключом REALITY авторизуются и безопасно выходят в интернет через VLESS-туннель.

## ⚡ Быстрая установка в 1 команду

Выполните команду на вашем сервере (от имени `root`):

```bash
bash <(curl -sSL https://raw.githubusercontent.com/iliy-git/selfsteal/main/install.sh)
```

Также можно передать домен и email в качестве аргументов:
```bash
bash <(curl -sSL https://raw.githubusercontent.com/iliy-git/selfsteal/main/install.sh) mysite.example.com admin@example.com
```

## 🚀 Что делает скрипт полностью автоматически:

1. **Проверяет и ставит зависимости:** `curl`, `git`, `socat`, `certbot`, `python3`, `qrencode`, а также `Docker` и `Docker Compose` (если они еще не установлены).
2. **Проверяет DNS A-запись:** сверяет, направлен ли введенный домен на публичный IP вашего VPS.
3. **Выпускает SSL-сертификат Let's Encrypt:** получает валидный TLS-сертификат и настраивает автоматический хук продления.
4. **Запускает сайт в Docker:** поднимает изолированный контейнер Nginx (`selfsteal_site`), слушающий `127.0.0.1:8443`.
5. **Настраивает 3x-ui:**
   * Автоматически находит базу `/etc/x-ui/x-ui.db`.
   * Создает резервную копию базы данных.
   * Настраивает инбаунд VLESS REALITY: переводит на порт `443`, устанавливает `Target (Dest)` в `127.0.0.1:8443` и `SNI` в ваш домен.
   * Перезапускает сервис `x-ui`.
6. **Выполняет самопроверку:** тестирует ответ 443 порта и корректность выдачи сертификата.
7. **Генерирует готовую ссылку:** выводит готовую `vless://` ссылку и QR-код для моментального сканирования камерой телефона.

## 📱 Поддерживаемые клиенты

Сгенерированная ссылка импортируется в 1 клик в любое приложение с поддержкой VLESS REALITY:
* **Android:** v2rayNG, Happ, Nekobox, Hiddify, Clash Verge
* **iOS:** Happ, Streisand, Shadowrocket, Sing-box, FoXray
* **Windows / macOS / Linux:** v2rayN, Nekoray, Hiddify, Clash Verge Rev

## 🛠️ Ручная установка через Git

Если вы хотите предварительно изучить или изменить исходный код сайта перед запуском:

```bash
cd /root
git clone https://github.com/iliy-git/selfsteal.git
cd selfsteal
chmod +x setup.sh install.sh
./setup.sh
```

### Параметры `setup.sh`:
* `-d, --domain <домен>` — доменное имя.
* `-e, --email <email>` — email для Let's Encrypt.
* `--no-xui` — развернуть только веб-сайт в Docker без изменения базы 3x-ui.

---

## 🔍 Проверка работоспособности

Чтобы убедиться, что маскировка работает корректно со стороны интернета, выполните с любого внешнего устройства:

```bash
curl -Iv https://ваш-домен.com/
```

Вы должны увидеть:
* `Connected to ваш-домен.com (IP) port 443`
* `SSL certificate verify ok (issuer: Let's Encrypt)`
* `HTTP/2 200 OK`

```text
    ├── index.html                 # Адаптивный HTML5 сайт
    ├── style.css                  # Стили сайта
    └── script.js                  # Интерактивные скрипты
```
