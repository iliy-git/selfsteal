# 🌐 SelfSteal SNI Site — Автоматический установщик сайта-маскировки

Автоматическое развертывание персонального сайта-визитки в Docker с официальным SSL-сертификатом **Let's Encrypt** на стандартных портах **80** и **443** для маскировки **VLESS REALITY** на любых серверах.

---

## 🎯 Зачем это нужно?

Многие современные хостинг-провайдеры (Node / Nodehost, Hetzner и др.) запрещают указывать в REALITY чужие популярные домены (`microsoft.com`, `apple.com`, `samsung.com`) и блокируют серверы за нарушение TOS. 

**Решение:**
1. Вы привязываете собственный домен к серверу.
2. Этот скрипт поднимает настоящий рабочий веб-сайт на портах **80** и **443** с валидным зеленым SSL.
3. Сайт **открывается в обычном веб-браузере** у любого пользователя и сканера хостинга.
4. Вы можете прописать этот сайт в REALITY **в любом инбаунде на любом сервере**!

---

## ⚡ Быстрая установка в 1 команду

Выполните команду на сервере от имени `root`:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/iliy-git/selfsteal/main/install.sh)
```

Также можно передать домен и email аргументами:
```bash
bash <(curl -sSL https://raw.githubusercontent.com/iliy-git/selfsteal/main/install.sh) mysite.com admin@mysite.com
```

---

## 🚀 Что делает скрипт полностью автоматически:

1. **Проверяет и ставит зависимости:** `curl`, `git`, `socat`, `certbot`, `python3`, `Docker` и `Docker Compose`.
2. **Проверяет DNS A-запись:** сверяет, направлен ли введенный домен на публичный IP вашего VPS.
3. **Выпускает SSL-сертификат Let's Encrypt:** получает официальный бесплатный TLS-сертификат и настраивает хук автопродления.
4. **Открывает порты:** гарантирует доступность портов `80` (HTTP -> редирект на HTTPS) и `443` (HTTPS) в файрволе.
5. **Запускает сайт в Docker:** поднимает изолированный контейнер Nginx (`selfsteal_site`) со стильным адаптивным сайтом-визиткой.
6. **Выполняет проверку:** тестирует коды ответа по HTTP и HTTPS.

---

## ⚙️ Как прописать сайт в REALITY (3x-ui / Xray)

После запуска скрипта сайт полностью готов. Теперь на **любом** сервере в **любом** инбаунде укажите:

* **Target (Dest):** `ваш-домен.com:443`
* **SNI (serverNames):** `ваш-домен.com`
* **SpiderX:** `/`

> 💡 **Сайт полностью независим:** скрипт не трогает базу 3x-ui и ваши инбаунды — вы настраиваете и создаете инбаунды так, как вам удобно.

## 🔍 Проверка работы сайта

Откройте ваш домен в браузере или проверьте через терминал:

```bash
curl -Iv https://ваш-домен.com/
```

Вы должны увидеть:
* `Connected to ваш-домен.com (IP) port 443`
* `SSL certificate verify ok (issuer: Let's Encrypt)`
* `HTTP/2 200 OK`

## 📂 Структура репозитория

```text
selfsteal/
├── install.sh                     # Быстрый установщик через curl
├── setup.sh                       # Главный мастер развертывания
├── docker-compose.yml             # Конфигурация контейнера Nginx (порты 80 и 443)
├── nginx/
│   └── conf.d/
│       └── default.conf.template  # Шаблон Nginx с редиректом и SSL
└── html/                          # Исходные файлы сайта-визитки
    ├── index.html                 # Адаптивный HTML5 сайт
    ├── style.css                  # Стили сайта
    └── script.js                  # Интерактивные скрипты
```
