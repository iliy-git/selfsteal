# 🌐 SelfSteal SNI Business Card Site (Docker)

Готовое решение для развертывания персонального сайта-визитки / портфолио в Docker с автоматическим получением SSL-сертификата Let's Encrypt. 

Идеально подходит для реализации схемы **SelfSteal SNI** (Steal Yourself) в прокси-протоколах **VLESS REALITY / ShadowTLS / Trojan** в соответствии с новыми правилами хостинг-провайдеров.

---

## 🎯 Зачем это нужно?

Хостинг-провайдеры (например, Node / Nodehost) запрещают указывать в REALITY чужие ресурсы (`microsoft.com`, `apple.com`, `tesla.com`, `nvidia.com`) и требуют **SelfSteal SNI**:
1. Ваш собственный домен направлен на IP вашего сервера.
2. На сервере открывается **настоящий веб-сайт** с **валидным SSL-сертификатом**.
3. При любой внешней проверке сервер отвечает как обычный легитимный веб-сайт.

Этот репозиторий разворачивает современный, стильный сайт-визитку в Docker-контейнере Nginx, монтирует сертификаты Let's Encrypt и слушает порт `127.0.0.1:8443`.

---

## 🚀 Быстрый старт

### 1. Направьте домен на сервер
В DNS-панели вашего регистратора добавьте **A-запись**, указывающую на IP вашего VPS:
```text
@   A   <IP_ВАШЕГО_СЕРВЕРА>
```

### 2. Запустите скрипт установки
Перейдите в директорию репозитория и запустите `setup.sh`:
```bash
cd /root/selfsteal-site
chmod +x setup.sh
./setup.sh
```

Скрипт интерактивно:
1. Запросит ваш домен.
2. Проверит DNS A-запись (резолвится ли домен на IP сервера).
3. Автоматически выпустит бесплатный SSL-сертификат Let's Encrypt через Certbot.
4. Сгенерирует `.env` и конфиг Nginx.
5. Запустит Docker Compose.
6. Выполнит проверку здоровья сайта.

Также поддерживается неинтерактивный запуск:
```bash
./setup.sh mydomain.com myemail@gmail.com
```

---

## ⚙️ Настройка в 3x-ui / Xray (SelfSteal)

После успешного выполнения `setup.sh`:
1. Откройте панель 3x-ui (`Входящие подключения` -> редактировать инбаунд VLESS REALITY).
2. В блоке **Reality**:
   * **Target (Dest):** `127.0.0.1:8443`
   * **SNI (serverNames):** ваш домен (например, `mysite.com`)
3. Сохраните изменения и перезагрузите подключение.
4. В клиентском приложении (v2rayNG, Nekobox, Streisand) в поле **SNI / ServerName** укажите ваш домен.

```text
    └── script.js                   # Интерактивные элементы, меню, форма
```

## 🔄 Автопродление сертификата

Сертификаты Let's Encrypt продлеваются системным таймером `certbot.timer`. 
После обновления сертификата Nginx в контейнере автоматически подхватывает новые ключи (или можно настроить хук: `docker compose restart selfsteal-site`).
